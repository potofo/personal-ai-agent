## 出力形式（最重要：テキストチャットでは必ずインフォグラフィック）
テキストチャットでは、依頼の言い方（「まとめて」「教えて」など）にかかわらず、Web 検索で予報を確認したうえで、次の順に出力する。
1. 一言の導入（1 文）
2. ```html のコードブロックでインフォグラフィックを 1 つ（画面がそのまま図として描画する）
3. コードブロックの後に、出典（サイト名と URL）と「予報は変わるので出かける前に再確認を」の一言を Markdown で

インフォグラフィックの作り方:
- 自己完結した HTML。インラインの CSS と SVG・絵文字だけを使う（<script>、外部の画像・フォント・CSS は使わない）
- 幅は 100%（最大 760px）。日ごとのカードは flex-wrap で並べ、スマートフォンでも崩れないようにする
- 構成: ヘッダー（地域・期間・出典）→ 日ごとのカード（日付と曜日、天気アイコン ☀️☁️🌧️❄️、最高／最低気温、降水確率）→ 気温の推移（SVG の折れ線、任意）→ 服装の目安と注意点の帯
- 雨の日は色やバッジで目立たせ、文字は 12px 以上にする

音声チャットでは HTML を出さず、要点を口頭で伝える。

## 使い方
### 入力
地域を指定して「週間天気」「今週の天気」「〇〇（都道府県・市区町村）の予報」などと聞く。

### 出力方針（見た目重視）
テキスト応答は、アイコンと短い説明を組み合わせて視覚的に理解しやすくする。必要な情報は、次の順で大まかに提示。
- 気温の傾向（朝／日中／夜の3段階）をアイコン付きで示す
  - 晴れの予報：☀️（日中は暖かいが朝夕は冷えやすいなど）
  - 曇りの予報：☁️（薄着と軽めの羽織を提案）
  - 雨の予報：🌧️（傘必須、タイミングの注意）
  - 風の注意がある場合は、🌬️などで補足
- 降水の確率・タイミングのヒント
- 服装の目安（例：薄手のコート、傘、折り畳み傘など）
- 注意点（道路のぬかるみ、交通の乱れ、低体温や熱中症など、季節ごとの注意）
- 出典（サイト名）と、更新確認の促し

表現は会話っぽく、かつ情報はコンパクトにまとめる。依頼が「箇条書きがいい」と言われた場合は、箇条書き中心で出力する。

## 参考形式
- アイコン＋1行の見出し＋短い補足：視覚的に分かりやすい
- 気温の見出し：朝／日中／夜（例：🕯️朝は涼しい、暖かい服が安心）
- 降水：🌧️雨が予想される時間帯を一言で伝える

## 注意
予報は更新される可能性があるため、必ず最新情報を公式気象情報や信頼できる気象サイトで再確認するよう促す。参照を優先し、情報源は明示する。
